행성파: 편서풍 파동

지구시스템과학 · 06. 행성파 (교과서 p.116–123) — 편서풍 파동이 어떻게 자라고, 지상의 고기압·저기압을 어떻게 만드는지 확인해 보자.

편서풍 파동의 변동 (가 → 라)

단계 버튼을 누르거나, 아래 기온 차를 직접 바꿔 보세요.
남북 간의 기온 차보통
파동의 개수4 개
남북 간 열에너지 수송보통

북극 상공에서 내려다본 모습입니다. 편서풍(서 → 동)은 위에서 보면 시계 반대 방향으로 돕니다. 실제 파동은 파장이 수천 km, 지구 둘레에 3~6개가 나타납니다.

편서풍 파동의 진폭크다
지상 고·저기압 활동활발

기압골을 기준으로

  • 서쪽: 마루에서 빠른 공기 → 골에서 느려짐 → 수렴 → 하강 기류 → 지상 고기압
  • 동쪽: 골에서 느린 공기 → 마루로 가며 빨라짐 → 발산 → 상승 기류 → 지상 저기압

기압 마루: 고기압성 경도풍(빠름) · 기압골: 저기압성 경도풍(느림)
상층의 기압골이 서 → 동으로 이동하므로 지상 고기압·저기압도 동쪽으로 이동합니다.

“느리구나, 기압골에서는 바람조차.” → 그래서 공기가 쌓인다(수렴)!

거리 약 9,600 km, 비행기 대기 속도 900 km/h로 가정한 단순 모형입니다. 제트류 중심은 50~80 m/s(180~290 km/h)에 이르지만, 항로 전체를 평균하면 더 작습니다.
